# 引航登离轮海况推演系统

浏览器内的引航登离轮海况推演与决策辅助系统。TypeScript + WebGPU，海面用方向谱 FFT 自写 compute shader，登轮点、船舶、作业记录全部持久化在 IndexedDB。

## 核心数值指标（已自动化验收）

| 指标 | 要求 | 实测口径 | 测试 |
| --- | --- | --- | --- |
| FFT 海面有效波高 | 与输入 Hs 误差 < 3% | 512×512 海面、120 帧空间+时间统计，覆盖深水/浅水/风浪涌浪混合 | `acceptance.test.ts` |
| 软梯-引航艇相对垂向运动 | 时域有义值 vs 频域 RAO+方向谱积分 < 5% | 8 次独立相位实现集合平均，位移与速度分别比对 | `acceptance.test.ts` |
| 512×512 海面实时 | 每帧不卡顿 | radix-2 FFT 全在 GPU compute，渲染器回传帧耗时/FPS | 推演页实时显示 |

运行 `npm test` 执行全部 28 项测试（数值验收 + 端到端冒烟）。

## 数值方法

- **色散关系**：有限水深 `ω² = g·k·tanh(k·h)`，Newton 反解 k(ω)，Eckart 近似作初值；深水自动退化为 `ω²=gk`。
- **方向谱**：JONSWAP（γ 可调）按目标 Hs 反标定 α，方向分布 cos²ˢ（s 可调，数值归一化），风浪/涌浪多分量叠加。
- **FFT 海面**：方向谱极坐标积分到 k 网格（四邻域 splat 能量守恒），Hermitian 共轭系数 + 随机相位，离散 Parseval 严格保方差；GPU 与 CPU 共用同一份振幅系数，同源同结果。
- **船舶运动**：RAO 复传递函数（heave/pitch/roll），船上点垂向传递 `1 + H_heave + y·H_roll − x·H_pitch`；无表时按船宽与 GM 粗估横摇固有周期并生成解析 RAO。
- **相对运动**：时域谐波相干合成（解析速度，无差分误差），频域 `∫|H_rel|²·S dωdθ`，两者同谱同离散，集合平均后偏差 < 5%。
- **遮蔽区**：半经验绕射几何模型，全航向扫描给出下风舷遮蔽最优航向。
- **软梯**：单摆一阶滞后模型，输出贴壳间隙、底端出水高度，干舷 > 9 m 自动提示组合梯。

## 六个页面

1. **登轮点档案**：水深、主浪向、潮流；浅水点显示色散修正幅度。
2. **船舶运动库**：主尺度、干舷吃水、软梯位；RAO 表导入或解析生成，横摇固有周期粗估。
3. **海况输入**：手填风浪/涌浪（Hs/Tp/浪向/γ/s），浮标方向谱导入（坏行、缺频段自动告警），实时谱图与 Hs 核对。
4. **登轮推演**：WebGPU 三维 FFT 海面、大船/引航艇/软梯、夜间灯光、相对位移速度双曲线（超限标红）、航向扫描、安全窗口统计。
5. **作业记录**：每次登离轮存海况快照与随机种子，支持同种子原样回放，按登轮点与 Hs 分档统计可登率。
6. **站务设置**：全站与单登轮点阈值（停航 Hs、相对位移/速度上限、组合梯规则），一键出当班可行性单。

## 运行

```bash
npm install
npm test        # 数值验收 + 冒烟测试（Node，无需浏览器）
npm run dev     # 开发服务器
npm run build   # 类型检查 + 生产构建
```

不支持 WebGPU 的浏览器自动降级为 CPU 数值推演（曲线、扫描、可行性判定保留，无 3D）。

## 目录

```
src/core   纯 TS 数值核（色散/谱/FFT/波场/RAO/响应/遮蔽/软梯/浮标），可在 Node 测试
src/gpu    WebGPU 渲染器、WGSL compute shader、运动采样、场景控制
src/db     IndexedDB 仓储与出厂种子数据
src/app    状态中心、路由、六个页面与 Canvas 图表
test       数值验收与端到端冒烟测试
```
